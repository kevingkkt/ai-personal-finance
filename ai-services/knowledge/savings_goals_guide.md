# Savings Goals Guide

## Purpose
The Savings Goals feature records savings targets and contributions.
It provides educational information about the application, not investment,
tax, credit, or professional financial advice.

## Creating a goal
A savings goal contains a goal name, target amount, and target date.
The target amount must be greater than zero. Dates use DD-MM-YYYY.

## Contributions
A contribution records an amount and a contribution date for one goal.
Contribution amounts must be greater than zero.
The current saved amount equals the sum of that goal's contributions.
Adding, editing, or deleting a contribution updates the current saved amount.

## Remaining amount
The remaining amount is the target amount minus the current saved amount.
If the current saved amount is greater than the target, the remaining amount is zero.

## Progress percentage
Progress percentage is calculated as current saved amount divided by target amount,
multiplied by 100. The calculation may exceed 100 percent when savings exceed the target.

## Goal status
A goal is completed when the current saved amount reaches or exceeds the target.
An incomplete goal is overdue when its target date is before the reference date.
An incomplete goal is due today when its target date equals the reference date.
Other incomplete goals are active.

## Days remaining
Days remaining is the number of calendar days from the reference date to the target date.
A negative result means the target date has passed.

## Limits of knowledge answers
This guide explains the application's rules.
It does not contain a user's live balances or contribution history.
Use the selected goal's progress calculation to see its current numbers.
The guide does not specify bank interest rates or predict investment returns.
